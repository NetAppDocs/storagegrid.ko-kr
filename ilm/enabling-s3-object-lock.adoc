= StorageGRID에서 S3 Object Lock 활성화
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오브젝트 데이터를 저장할 때 S3 테넌트 계정이 규정 요구사항을 준수해야 하는 경우 전체 StorageGRID 시스템에 대해 S3 오브젝트 잠금을 활성화해야 합니다. 글로벌 S3 오브젝트 잠금 설정을 활성화하면 모든 S3 테넌트 사용자가 S3 오브젝트 잠금을 통해 버킷과 오브젝트를 생성하고 관리할 수 있습니다.

.시작하기 전에
* 이 link:../admin/admin-group-permissions.html["루트 액세스 권한"]있습니다.
* 을 사용하여 그리드 관리자에 로그인되어 있습니다.link:../admin/web-browser-requirements.html["지원되는 웹 브라우저"]
* S3 오브젝트 잠금 워크플로우를 검토하고 고려 사항을 이해합니다.
* 활성 ILM 정책의 기본 규칙이 규정을 준수함을 확인했습니다. 자세한 내용은 link:creating-default-ilm-rule.html["기본 ILM 규칙을 생성합니다"]을 참조하십시오.


.이 작업에 대해
그리드 관리자는 글로벌 S3 오브젝트 잠금 설정을 활성화하여 테넌트 사용자가 S3 오브젝트 잠금이 활성화된 새 버킷을 생성할 수 있도록 해야 합니다. 이 설정을 사용하도록 설정한 후에는 비활성화할 수 없습니다.

S3 객체 잠금을 활성화한 후, 그리드 관리자는 테넌트 사용자가 기존 버킷에 대해 S3 객체 잠금을 활성화할 수 있도록 허용할 수도 있습니다. 그리드 관리자는 이 설정을 활성화한 후 비활성화할 수도 있습니다. 자세한 내용은 link:requirements-for-s3-object-lock.html#s3-object-lock-existing-buckets["S3 객체 잠금 요구 사항"]을 참조하십시오.

글로벌 S3 Object Lock 설정을 활성화한 후 기존 테넌트의 규정 준수 설정을 검토하십시오. 이 설정을 활성화하면 테넌트가 생성된 시점의 StorageGRID 릴리스에 따라 S3 오브젝트 잠금 설정이 달라집니다.


NOTE: 전역 규정 준수 설정이 더 이상 사용되지 않습니다. 이전 버전의 StorageGRID를 사용하여 이 설정을 활성화한 경우 S3 오브젝트 잠금 설정이 자동으로 활성화됩니다. StorageGRID를 계속 사용하여 기존 규정 준수 버킷의 설정을 관리할 수 있지만, 새로운 규정 준수 버킷을 생성할 수는 없습니다. 자세한 내용은 https://kb.netapp.com/Advice_and_Troubleshooting/Hybrid_Cloud_Infrastructure/StorageGRID/How_to_manage_legacy_Compliant_buckets_in_StorageGRID_11.5["NetApp 기술 자료: StorageGRID 11.5에서 레거시 준수 버킷을 관리하는 방법"^]을 참조하십시오.

.단계
. *구성* > *시스템* > *S3 개체 잠금*을 선택합니다.
+
S3 오브젝트 잠금 설정 페이지가 나타납니다.

. StorageGRID 시스템 전체에 S3 객체 잠금을 활성화하려면 *S3 객체 잠금 활성화*를 선택하십시오.
. 선택적으로 *기존 버킷에서 S3 객체 잠금을 활성화하도록 허용*을 선택할 수 있습니다.
+

CAUTION: 기존 버킷에 S3 객체 잠금을 활성화하면 ILM 규칙에 따라 클라우드 스토리지 풀에서 StorageGRID로 의도치 않은 데이터 마이그레이션이 발생할 수 있습니다. 이 마이그레이션은 시작되면 중지할 수 없습니다. 자세한 내용은 link:requirements-for-s3-object-lock.html#s3-object-lock-existing-buckets["S3 객체 잠금 요구 사항"]을 참조하십시오.

. Apply * 를 선택합니다.
+
S3 오브젝트 잠금을 사용하도록 설정한 후 해제할 수 없다는 확인 대화 상자가 나타납니다.

. 전체 시스템에 대해 S3 오브젝트 잠금을 영구적으로 활성화하려면 * OK * 를 선택합니다.
+
OK * 를 선택한 경우:

+
** 활성 ILM 정책의 기본 규칙이 호환되는 경우 S3 오브젝트 잠금이 전체 그리드에 대해 활성화되며 비활성화할 수 없습니다.
** 기본 규칙이 규정을 준수하지 않으면 오류가 발생합니다. 규정을 준수하는 규칙을 기본 규칙으로 포함하는 새 ILM 정책을 생성하고 활성화해야 합니다. *확인*을 선택합니다. 그런 다음 새 정책을 생성하고 시뮬레이션한 후 활성화합니다. 지침은 link:creating-ilm-policy.html["ILM 정책을 생성합니다"]을 참조하십시오.
