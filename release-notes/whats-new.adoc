= StorageGRID 12.1의 새로운 기능
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.1에서는 다음과 같은 기능 및 기능 변경 사항이 도입되었습니다.

최근 StorageGRID 12.1 릴리스의 수정된 문제 및 알려진 문제에 대한 자세한 내용은 https://library.netapp.com/ecm/ecm_download_file/ECMLP3373065["StorageGRID 12.1 릴리스 노트"^]를 참조하십시오. NetApp 계정으로 로그인하거나 계정을 생성하여 릴리스 노트에 액세스해야 합니다.

[[s3]]
== S3



[[enable-s3-object-lock-on-existing-buckets]]
=== 기존 버킷에 S3 Object Lock 활성화

'기존 버킷에 대한 S3 객체 잠금 허용' 설정이 활성화되면 S3 테넌트 계정은 기존 버킷에 대해 S3 객체 잠금을 활성화할 수 있습니다. S3 테넌트 계정이 기존 버킷에 대해 S3 객체 잠금을 활성화한 후에는 비활성화할 수 없습니다.



[[replication-allowed-for-s3-object-lock-enabled-buckets]]
=== S3 객체 잠금이 활성화된 버킷에 대해 복제가 허용됩니다.

이제 CloudMirror를 사용하여 S3 Object Lock이 활성화된 버킷의 객체를 복제할 수 있습니다. link:../tenant/considerations-for-platform-services.html["플랫폼 서비스에 대해 알아보기"]을 참조하십시오.



[[enable-cross-grid-replication-for-non-empty-buckets]]
=== 비어 있지 않은 버킷에 대해 그리드 간 복제 활성화

이제 비어 있지 않은 버킷에 대해 그리드 간 복제를 활성화할 수 있습니다. link:../admin/grid-federation-what-is-cross-grid-replication.html#requirements-for-cross-grid-replication["크로스 그리드 복제 요구 사항"]을 참조하십시오.



[[s3-batch-operations-fpvr-only]]
=== S3 배치 작업(FPVR 전용)

버전 관리가 활성화된 버킷에 있는 기존 객체를 복제하려면 S3 배치 작업을 사용할 수 있으며, 이 버킷은 나중에 그리드 간 복제를 위해 구성할 계획입니다.

이 기능을 사용하려면 StorageGRID 12.1에 대한 FPVR 승인이 필요합니다. 이 기능을 사용하려면 담당 영업 담당자에게 문의하십시오.



[[non-functional-s3-rest-api-headers]]
=== 작동하지 않는 S3 REST API 헤더

 `If-Match` 및  `If-None-Match` 헤더는 S3 REST API link:../s3/put-object.html["PutObject 를 선택합니다"], link:../s3/complete-multipart-upload.html["CompleteMultipartUpload를 클릭합니다"], link:../s3/put-object-copy.html["CopyObject 를 선택합니다"], 및 link:../s3/operations-on-objects.html["DeleteObject 를 클릭합니다"]에 대해 허용되지만 작동하지 않습니다.

자세한 내용은 link:../release-notes/changes-to-s3-rest-api.html["StorageGRID S3 REST API 지원 변경 사항"]을 참조하십시오.



[[support-for-pre-calculated-checksum-values]]
=== 미리 계산된 체크섬 값 지원

S3 REST SPI는 이제 미리 계산된 체크섬 값과 `x-amz-checksum-type` 요청 헤더를 지원합니다. link:../s3/index.html#updates-to-rest-api-support["REST API 지원 업데이트"]을 참조하십시오.

[[tenants]]
== 테넌트



[[account-sync]]
=== 계정 동기화

이제 _account clone_ 기능은 특정 테넌트 계정 정보를 일회성으로 복제하는 것을 의미합니다.

_계정 동기화_는 하나 이상의 그리드 페더레이션 연결에 있는 StorageGRID 시스템 간에 테넌트 계정, 테넌트 그룹, 테넌트 사용자 및 S3 액세스 키를 자동으로 지속적으로 복제할 수 있는 새로운 기능입니다. 을 참조하십시오. link:../admin/grid-federation-what-is-account-sync.html["StorageGRID의 계정 동기화에 대해 알아보십시오"]



[[kafka-endpoints-and-mtls-authentication]]
=== Kafka 엔드포인트 및 mTLS 인증

이제 Kafka 엔드포인트에서 mTLS(상호 전송 계층 보안)가 지원됩니다. 자세한 내용은 link:../tenant/configuring-platform-services-endpoints.html["플랫폼 서비스 끝점을 구성합니다"]을 참조하십시오.



[[maximum-number-of-buckets]]
=== 최대 버킷 수

StorageGRID 시스템은 이제 각 S3 테넌트 계정당 최대 20,000개의 버킷을 지원합니다.
