= StorageGRID의 테넌트 관리 API 변경 사항
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.1은 테넌트 관리 API 버전 4를 사용합니다. 버전 4에서는 버전 3이 더 이상 사용되지 않지만, 버전 1, 2, 3은 여전히 지원됩니다.


NOTE: StorageGRID에서 더 이상 사용되지 않는 버전의 테넌트 관리 API를 계속 사용할 수 있지만, 이러한 API 버전에 대한 지원은 향후 StorageGRID 릴리스에서 제거될 예정입니다. StorageGRID 12.0 이상으로 업그레이드한 후에는  `PUT /grid/config/management` API를 사용하여 더 이상 사용되지 않는 API를 비활성화할 수 있습니다.

자세한 내용은 을 link:../tenant/understanding-tenant-management-api.html["테넌트 관리 API 이해"]참조하십시오.



[[new-api-for-object-replication]]
== 객체 복제를 위한 새로운 API

당신은 사용할 수 있습니다 `/org/cross-grid-replication/{versionId}/replicate` 새로 구성된 크로스 그리드 복제가 있는 기존 버킷에서 객체를 수동으로 복제하기 위한 API입니다.
