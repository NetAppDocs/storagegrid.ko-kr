= StorageGRID의 Grid Management API 변경 사항
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.1은 그리드 관리 API 버전 4를 사용합니다. 버전 4에서는 버전 3이 더 이상 사용되지 않지만, 버전 1, 2, 3은 여전히 지원됩니다.


NOTE: StorageGRID에서 더 이상 사용되지 않는 관리 API 버전을 계속 사용할 수 있지만, 이러한 API 버전에 대한 지원은 향후 StorageGRID 릴리스에서 제거될 예정입니다. StorageGRID 12.0 이상으로 업그레이드한 후에는  `PUT /grid/config/management` API를 사용하여 더 이상 사용되지 않는 API를 비활성화할 수 있습니다.

자세한 내용은 을 link:../admin/using-grid-management-api.html["Grid Management API를 사용합니다"]참조하십시오.

== BMC 암호 및 LAN IP 설정을 변경하기 위한 새로운 엔드포인트

다음 엔드포인트가 추가되어 사용자가 link:../harden/hardening-guidelines-for-storagegrid-nodes.html#change-appliance-bmc-password["어플라이언스 BMC 암호 변경"]할 수 있습니다.

`PUT /bmc-configuration/root-password`

다음 엔드포인트가 추가되어 link:../maintain/changing-nodes-network-configuration.html#change-appliance-node-bmc-lan-ip-settings["BMC LAN IP 설정을 변경하거나 확인합니다"]할 수 있습니다.

`PUT /grid/bmc/{node-id}/lan-ip-config`

`GET /grid/bmc/{node-id}/lan-ip-config`
