= StorageGRID 노드 복구 절차를 선택합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
오류가 발생한 노드 유형에 맞는 복구 절차를 선택하십시오.

[cols="1a,2a"]
|===
| 그리드 노드 | 복구 절차 


 a| 
스토리지 노드
 a| 
스토리지 노드 복구 절차는 장애 유형에 따라 다릅니다.

link:recovering-from-storage-node-failures.html["스토리지 노드 장애 복구"]



 a| 
관리자 노드
 a| 
관리 노드 절차는 기본 관리 노드 또는 비 기본 관리 노드 복구 여부에 따라 달라집니다.

link:recovering-from-admin-node-failures.html["관리자 노드 오류에서 복구"]



 a| 
게이트웨이 노드
 a| 
link:replacing-gateway-node.html["게이트웨이 노드에서 복구"]



 a| 
아카이브 노드
 a| 
https://docs.netapp.com/us-en/storagegrid-118/maintain/recovering-from-archive-node-failures.html["아카이브 노드 장애 복구(StorageGRID 11.8 문서 사이트)"^]

|===

NOTE: 하나 이상의 그리드 노드를 호스팅하는 서버에 장애가 발생하면 어떤 순서로든 노드를 복구할 수 있습니다. 그러나 장애가 발생한 서버가 기본 Admin Node를 호스팅하고 있고 비기본 Admin Node가 존재하지 않는 경우, 기본 Admin Node를 먼저 복구해야 합니다. 기본 Admin Node를 먼저 복구하면 다른 노드가 기본 Admin Node에 접속을 시도할 때 복구가 중단되는 것을 방지할 수 있습니다. 비기본 Admin Node를 사용할 수 있는 경우, 이를 사용하여 다른 노드를 복구할 수도 있으므로 기본 Admin Node에 접속하지 않고도 해당 복구를 진행할 수 있습니다.
