= StorageGRID에서 MAV 보호 작업 요청 관리
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MAV 관리자는 StorageGRID에서 MAV로 보호되는 작업에 대한 요청을 관리할 수 있습니다. 본인 또는 다른 사용자의 보류 중인 요청을 확인하고, 요청을 승인 또는 거부하고, 과거 요청 내역을 볼 수 있습니다.

.시작하기 전에
* MAV 관리자 그룹에 속해 있으며 link:../admin/admin-group-permissions.html["루트 액세스 권한"]이(가) 있습니다.
* 기본 관리자 노드에서 Grid Manager에 로그인했습니다.


.단계
. MAV 요청에 대한 이메일 알림을 받은 경우 *구성* > *다중 관리자 인증* > *기타 요청*을 선택하십시오.
+
또한, Grid Manager 대시보드에 보류 중인 MAV 요청에 대한 알림이 표시됩니다.

. 관리하려는 각 요청에 대해 라디오 버튼을 선택합니다.
. 선택한 요청을 승인하거나 거부하려면 *승인* 또는 *거부*를 선택하십시오.
. 이전 요청 내역을 보려면 *내역*을 선택하십시오.
