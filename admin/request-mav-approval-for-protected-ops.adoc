= StorageGRID에서 MAV 보호 작업에 대한 승인 요청
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 관리자 또는 사용자로서 StorageGRID에서 MAV로 보호된 작업을 시작하면 요청이 자동으로 생성됩니다. 해당 작업에 승인이 필요하다는 메시지가 표시됩니다.

StorageGRID 시스템은 MAV로 보호되는 작업을 정의합니다. MAV로 보호되는 작업을 시작하면 승인을 위해 MAV 관리자에게 요청이 전송됩니다.

.단계
StorageGRID 시스템은 MAV로 보호되는 작업을 시작했음을 알려줍니다.

. 필요에 따라 다음 작업 중 하나를 수행하십시오.
+
.. *구성* > *액세스 제어* > *다중 관리자 인증* > *내 요청*을 선택하여 요청 상태를 확인합니다.
+
*** *처리 중*. 요청이 접수되었습니다.
*** *만료됨*. 요청이 30일 이내에 처리되지 않았습니다. 또는 루트 액세스 권한이 있는 사용자가 MAV를 비활성화한 경우, 모든 보류 중인 요청이 만료됩니다.
*** *취소됨*. 사용자가 요청을 철회했습니다.
*** *승인됨*. MAV 관리자가 보류 중인 요청을 승인했습니다.
*** *거부됨*. MAV 관리자가 보류 중인 요청을 거부했습니다.


.. 다른 사용자의 보류 중인 요청을 확인하려면 *구성* > *액세스 제어* > *다중 관리자 인증* > *기타 요청*을 선택하십시오.
.. 작업을 취소하려면 *내 요청* > *_취소하려는 요청_* > *철회*를 선택하십시오.




MAV 관리자가 요청을 승인하면 작업이 자동으로 수행됩니다.

요청이 거부되면 작업은 수행되지 않으며, 필요한 경우 새 요청을 제출할 수 있습니다.
