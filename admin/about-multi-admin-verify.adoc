= StorageGRID 다중 관리자 인증에 대해 알아보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 관리자는 다중 관리자 검증(MAV) 기능을 사용하여 지정된 관리자의 승인을 받은 후에만 특정 작업을 수행할 수 있도록 설정할 수 있습니다. MAV는 StorageGRID 시스템에 대한 실수로 인한 또는 승인되지 않은 변경을 방지하는 데 도움이 됩니다.

MAV은 기본적으로 비활성화되어 있습니다.



[[mav-configuration-overview]]
== MAV 구성 개요

MAV를 구성하려면 다음 작업을 수행해야 합니다.

* 하나 이상의 관리자 그룹을 생성하십시오. MAV 관리자는 승인 및 거부 권한을 갖습니다.
* 다중 관리자 인증 기능을 활성화합니다.
* 보호된 작업 목록 중에서 선택하십시오.


초기 구성을 수행하고 나중에 수정하려면 사용자에게 루트 액세스 권한이 있어야 합니다.



[[how-protected-operations-are-handled-under-mav]]
== MAV 환경에서 보호된 작업이 처리되는 방식

MAV가 활성화된 경우, 보호된 모든 작업을 완료하려면 다음 단계가 필요합니다.

. 사용자가 작업을 시작하면 요청이 생성됩니다.
. 해당 작업을 수행하기 전에 최소 한 명의 MAV 관리자 승인을 받아야 합니다.
. 승인되면 MAV로 보호되는 작업이 자동으로 수행됩니다.
