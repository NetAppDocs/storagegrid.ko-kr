= 이메일 서버 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 관리자는 시스템 이벤트 및 문제에 대한 알림을 자신, 다른 관리자 및 기술 지원 담당자에게 보내는 StorageGRID 경고 및 모니터링 시스템의 이메일 서버를 구성해야 합니다.

알림에 이메일 서버를 사용하는 StorageGRID 기능에는 알림, AutoSupport 및 다중 관리자 인증(MAV)이 있습니다. 모든 알림에 동일한 이메일 서버를 사용할 수 있습니다.

.시작하기 전에
* 이 link:../admin/admin-group-permissions.html["루트 액세스 권한"]있습니다.
* 을 사용하여 그리드 관리자에 로그인되어 있습니다.link:../admin/web-browser-requirements.html["지원되는 웹 브라우저"]


.단계
. *구성* > *모니터링* > *이메일 서버*를 선택합니다.
+
이메일 서버 페이지가 나타납니다.

. 드롭다운 메뉴에서 *이메일 서버가 필요할 수 있는 기능 보기*를 선택합니다. 특정 기능에 대한 이메일 알림 설정에 필요한 세부 정보를 보려면 *보기*를 선택합니다.
+
그리드 관리자에서 해당 기능의 구성 페이지로 이동합니다. 각 기능의 구성 페이지에는 이메일 알림을 보내려면 이메일 서버가 필요하다는 안내 메시지가 표시됩니다.

. 이메일 서버 페이지에서 이메일 서버를 구성하려면 다음을 수행합니다.
+
.. 이메일 서버의 IP 주소 또는 FQDN을 입력하십시오.
.. 이메일 서버에서 사용하는 포트 번호를 선택하십시오. 기본값은 25입니다.
.. 인증을 요구하려면 *인증 사용*을 선택하고 사용자 이름과 비밀번호를 입력하십시오.
.. SMTP 서버의 신원 확인을 요구하려면 *전송 계층 보안(TLS) 사용*을 선택하십시오. 그런 다음:
+
... CA 번들을 제공합니다.
... SMTP 이메일 서버에서 이메일 발신자가 인증을 위해 클라이언트 인증서를 제공해야 하는 경우 *클라이언트 인증서 보내기*를 선택하십시오. 그런 다음 클라이언트 인증서와 개인 키를 제공하십시오.


.. 이메일 설정이 올바른지 확인하려면 발신자와 수신자를 입력하여 테스트 이메일을 보내세요. *보내기*를 선택하세요.
+
테스트 이메일이 전송되었음을 나타내는 확인 메시지가 나타납니다.

.. 모든 이메일 수신인의 확인란을 선택하고 테스트 이메일이 수신되었는지 확인합니다.
+

NOTE: 몇 분 이내에 이메일을 받지 못했거나 * 이메일 알림 실패 * 경고가 트리거된 경우 설정을 확인하고 다시 시도하십시오.

.. 다른 관리 노드에 로그인하고 테스트 이메일을 보내 모든 사이트의 연결을 확인합니다.
+

NOTE: 알림 알림을 테스트할 때는 모든 관리 노드에 로그인하여 연결을 확인해야 합니다. 이는 모든 관리 노드가 테스트 e-메일을 보내는 AutoSupport 패키지 테스트와 대조적입니다.



. 저장 * 을 선택합니다.
+
테스트 이메일을 보내도 설정이 저장되지 않습니다. *저장*을 선택해야 합니다.

+
이메일 설정이 저장됩니다.

. 이메일 서버를 사용하는 기능의 구성 페이지로 이동하여 이메일 알림 설정을 완료하십시오.
+
** link:../monitor/email-alert-notifications.html["경고"]. 알림의 경우 link:../monitor/snmp-alert-notifications.html["SNMP 알림 설정"]할 수도 있습니다.
** link:../monitor/configure-autosupport-grid-manager.html["AutoSupport"]. AutoSupport 패키지는 이메일, HTTPS 또는 HTTP를 통해 보낼 수 있습니다(HTTP는 권장하지 않습니다).
** link:../admin/configure-multi-admin-verify.html["다중 관리자 인증(MAV)"].
